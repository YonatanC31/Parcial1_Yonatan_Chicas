# Referencias de Figma

Esta carpeta contiene las tres referencias visuales solicitadas para comparar la implementación web con el diseño responsive del proyecto:

- `desktop.svg` — referencia Desktop, 1440 px.
- `tablet.svg` — referencia Tablet, 768 px.
- `mobile.svg` — referencia Mobile, 390 px.

Las referencias conservan la identidad visual definida en Figma: paleta verde, fondo claro, jerarquía tipográfica, controles de búsqueda/filtro y reorganización de tarjetas según viewport.
